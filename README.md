# Project Athena — Build Log

Athena is my self-hosted personal AI agent system, running on my home PC.
I'm a beginner building it in public, one step at a time.

## What it's built with
- **Hermes Agent** (Nous Research) — the agent framework that runs everything
- **Obsidian** — my notes vault, where the agents read and write
- **LM Studio** running **Qwen** — a local AI model, free and private
- **Discord** — how Athena messages me on my phone
- **Claude Code** — helps me set things up and fix them

## First feature: Executive Assistant
Every weekday morning it reads my weekly goals and to-do list, writes a daily
plan with the most important task first, and sends it to me on Discord.

## Build logs
Daily build logs live in the [`logs`](logs/) folder, one file per day
(`YYYY-MM-DD.md`): what I built, what broke, and what I learned.

My actual notes and goals stay private. Only these logs are public.
