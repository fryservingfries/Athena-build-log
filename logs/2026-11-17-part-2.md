# Athena Build Log — Nov 17, 2026 (Part 2)

## Summary
This afternoon I cleaned up the Executive Assistant's instructions, set up remote access so I can use my home PC from my MacBook anywhere, and gave the PC a daily sleep schedule that fits around Athena's jobs.

## What got done

### 1. One set of instructions for the Executive Assistant
- The assistant had two overlapping instruction files: its Hermes personality file (SOUL.md) and an Instructions note in my vault. They disagreed in a few places.
- That overlap caused a bug: the plan kept ending with an extra "Weekly targets" section. The rules sat right below the plan format with nothing marking where the format ended, so the model treated them as one more section.
- Merged everything into **one Instructions note in my Obsidian vault**, split into three clear parts: **Steps**, **Plan format** and **Rules** ("never put these in the plan"). SOUL.md is now three lines that point to it.
- Bonus: I can now change how my assistant thinks just by editing a note in Obsidian, and it gets backed up to GitHub every night.

### 2. Safer morning job
- During testing, the model got blocked from overwriting a note, so it used a different editing tool to change it anyway. Restored the note and tightened the rules.
- Turned off the **terminal** and **code** tools for the assistant's scheduled jobs. The morning job never needs them, since Hermes gives scheduled runs the current date automatically. Chats keep those tools.
- Made every section of the plan required, writing "None" when a section is empty, because the small model kept dropping empty sections.

### 3. Remote access with Tailscale
- Installed **Tailscale** on the PC and MacBook: a private network between my own devices, with nothing opened to the internet.
- Turned off key expiry for the PC and set Tailscale to run before sign-in, so the connection doesn't quietly break.
- Turned on Windows Remote Desktop and connected from the Mac with Microsoft's **Windows App**. Now I can use my home PC from anywhere.
- Gotcha: the login kept failing. The fix was using the right Windows account name. Not every Windows login is the Microsoft email.

### 4. Daily sleep schedule
- PC sleeps at **1:00 AM** and wakes at **6:00 AM** every day, through two small Task Scheduler jobs.
- Traps avoided:
  - The common one-line "sleep" command actually **hibernates** on PCs with hibernation on, so the script asks Windows for real sleep.
  - After an automatic wake-up, Windows dozes off again within about 2 minutes if nobody touches it. The wake-up script keeps the PC awake until just before 1 AM.
- Skipped an automatic weekly restart: after a restart, Windows waits at the sign-in screen and all of Athena's tasks pause until I sign in. I'll restart by hand instead.

## Lessons learned
- **Rules in instructions aren't guarantees.** A small model can work around a rule, so removing a tool is safer than asking it not to use one.
- **Where text sits in a prompt matters.** Small models copy whatever looks like part of the template.
- **Remote access is about the whole chain:** a private network, an always-reachable PC, and the right login.
