# Athena Build Log — Nov 15–16, 2026

## Summary
Athena's first feature, the Executive Assistant, is built and automated. Every weekday at 7:30 AM it reads my weekly goals and to-do list, writes a daily plan with the #1 most important task first, saves it to my Obsidian vault, and sends it to my phone through Discord.

## What got done

### 1. Real goals in the vault
- Replaced the placeholder lines in Weekly Goals and To-Do with my real goals for the week.
- Areas: my top weekly goal (#1), Athena / AI Experience, YouTube & Editing, Fitness & Climbing.
- Weekly targets are split across weekdays (e.g. 10 = 2 per weekday).

### 2. Dedicated Hermes profile for the Executive Assistant
- Created a separate Hermes profile called `assistant`, cloned from my main setup, so it runs on its own with fresh memory.
- Wrote its instructions (SOUL.md): where my notes live, the plan format, and how to think (biggest-impact task first, direct, no fluff — Alex Hormozi style).
- Gave it exact file paths so it stops searching. Daily plan time dropped from several minutes to about 1 minute.
- Tip learned: Hermes on Windows keeps profiles in `AppData\Local\hermes`, not `~/.hermes`.

### 3. Automatic morning briefing
- Scheduled job "Morning briefing": every weekday at 7:30 AM Central.
- Used Claude Code to fix the job's settings: correct folder, time zone locked to Central, and fully self-contained instructions (scheduled jobs don't remember past chats).
- The job never overwrites an existing note. It saves a copy instead.

### 4. Daily plan delivered on Discord
- Created a second Discord bot, Athena Assistant, so it doesn't conflict with my main Athena bot.
- Made a private Athena server with a #daily-briefing channel and set it as the bot's home channel.
- Switched the morning job to deliver to Discord and removed the "Cronjob Response" wrapper, so the message is just the plan.

### 5. Hermes starts by itself
- Installed the Hermes gateway as a Windows startup task, so the bot and scheduler come back on their own after login.

## Lessons learned
- Small local models are fine for routine work, weak at setup. Qwen took ~6 minutes and 6 failed attempts to create one scheduled job. Claude Code (or exact commands) is much faster for setup and fixes.
- Know where you're typing. `PS C:\Users\...>` is PowerShell (commands). `❯` is the Hermes chat (sentences).
- Test the way it will really run. A test on a day that already had a briefing didn't prove the normal case.
- New bot tokens need a gateway restart before the bot responds.
- Hermes blocks scheduled jobs from running code on their own. Good safety default.

## Known issues
- The plan sometimes adds an extra "Weekly targets" section. Cause: two instruction sources (SOUL.md and Instructions.md) overlap.
